### Maintainer notes

Periodic Table (`io.github.GITHUB_USERNAME.periodic-table`) is a pure Quickshell QML bar widget (`BarWidget.qml`, `Panel.qml`, `BohrCanvas.qml`, `ElementsData.js`) that opens an interactive 18x10 periodic table popup from the Omarchy top bar. Hovering or navigating with keyboard arrows/Vim keys shows basic element details and valence electron counts, and clicking "More Details" (`Enter` / `M`) expands a deep-chemistry drawer with an animated 2D Bohr orbital canvas, oxidation states, electronegativity, crystal structure, and chemical reactivity.

The plugin is 100% self-contained QML/JS with zero external dependencies, zero privilege requests, zero network calls, and no custom installer scripts. Installation (`omarchy plugin add`), configuration (`omarchy bar move`), and removal (`omarchy plugin remove`) use only the native Omarchy plugin manager and are documented in `README.md`. License: MIT (`LICENSE` at root). Preview image: `preview.png` at root.
